# Weekly Report Template

Instructions for creating a new bi-weekly report. Delete this section in the actual report.

## Conventions

- **Filename**: `YYYY-MM-DD.md` (start date and end date of the reporting period).
- **Tone**: concise and concrete. Report what shipped, what was measured, and what's blocked. 

## Structure

```markdown
# CANS Protocol — Weekly Report: <date range>

## Executive Summer

## Progress

### Code
### Cooperation and Documentation
### Formal Methods

## Plans

### Code
### Cooperation and Documentation
### Formal Methods

## Problems

### Code
### Cooperation and Documentation
### Formal Methods

```
