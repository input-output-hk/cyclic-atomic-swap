# 2. Architecture Constraints

| # | Constraint                   | Rationale                                                                                                                                                                                                                                                      |
|---|------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | Apache 2.0 Licence           | IOG rules to publish open source promoting commercial interests, protecting intellectual property                                                                                                                                                              |
| 2 | Atomic Swap Test Environment | Re-use the proven [BTC-DeFi Atomic Swap Test Environment](https://github.com/input-output-hk/btc-defi-atomic-swaps-test-env) to prove the protocol functionalities and allow IOG to show it plublicly at run time.                                             |                                                                                                                                                                                                                                     
| 3 | Code in Rust                 | 1. Rust is the language preferred by the actual IOG.<br/>2. Proven [MuSig2](https://docs.rs/musig2/latest/musig2/) library.<br/>3. Multithread safety and efficiency.<br/>4. Comply [FIPS 140.3](https://csrc.nist.gov/pubs/fips/140-3/final) recommendations. |
| 4 | Code Instrumentation         | Provide logging and telemetry support for monitoring and debugging a distributed application.                                                                                                                                                                  |
| 5 | Use Bitcoin                  | 1. Untap the largest reserve of cryptocurrency liquidity to support IOG DeFi.<br/>2. Show the proposed protocol works in Bitcoin.                                                                                                                              |                                                                                                                                                                                                                                     
| 6 | Use Cardano                  | 1. Promote IOG Cardano.<br/> 2. Show the proposed protocol works in Cardano.                                                                                                                                                                                   |                                                                                                                                                                                                                                     

> `#.<contraint>` will be used to reference the constraints in the [Solution Strategy](./4_ss.md) section.
